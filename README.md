| [ScreenCompass](ScreenCompass/) | Halrad sensord ScreenCompass
Always the right angle
ScreenCompass is a lightweight Windows utility that gives you fast, reliable control over your screen orientation. Designed for tablets and convertible devices, it works with or without a hardware sensor, letting you rotate your display instantly using touch, mouse, keyboard, or automatic sensor input.
Whether you prefer manual precision or hands free auto rotation, ScreenCompass keeps your device aligned with your workflow. It runs quietly in the system tray, ready whenever you need it.
⭐ Key Features
•	Instant rotation with double tap, hotkeys, or tray menu
•	Auto rotate support for devices with orientation sensors
•	Rotation lock to keep your screen steady when needed
•	Global hotkeys (Ctrl + Alt + Arrow keys)
•	Touch, mouse, and keyboard friendly
•	Lightweight single file app (~500 KB)
🖥️ Perfect For
•	Windows tablets
•	2 in 1 convertibles
•	Docked/undocked workflows
•	Multi monitor setups
•	Users who want fast, predictable rotation control
📦 Requirements
•	Windows 10 or later
•	Orientation sensor optional
